\section{Budget}
\begin{heguidance}
Edit each partner's budget in that partner's admin-form file. Values are in EUR
unless stated otherwise. Leave unavailable amounts blank and enter zero explicitly
where applicable. Use \texttt{make budget-check} to check arithmetic and report
consortium totals. The detailed cost categories below follow the supplied standard
RIA reference; the selected call determines the applicable budget form.
\end{heguidance}
